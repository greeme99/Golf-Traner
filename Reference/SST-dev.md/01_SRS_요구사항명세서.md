
# 요구사항 명세서(SRS)

## 1. 프로젝트 개요
AI 기반 골프 스윙 분석 및 스마트 레슨 플랫폼

## 2. 목적
- 사용자 스윙 업로드/촬영
- AI 표준 스윙 및 프로 선수 비교
- 교정 포인트 및 레슨 제공

## 3. 이해관계자
- 골퍼
- 레슨 프로
- 관리자

## 4. 기능 요구사항
- 회원가입/로그인
- 영상 업로드
- 포즈 추정(MediaPipe)
- 스윙 단계 분석(SwingNet/GolfDB)
- 프로 스윙 비교
- AI 피드백 생성
- 분석 이력 관리

## 5. 비기능 요구사항
- 모바일 지원
- 분석시간 30초 이내
- 개인정보 보호
- API 기반 확장

## 6. 범위
### In Scope
- MVP 스윙 분석
- AI 피드백
- 비교 영상

### Out of Scope
- 실시간 센서 연동
- 웨어러블 연동
- 코치 예약
