# 구술 스텍과 MVP 개발 로드맵

골프 스윙 분석 앱의 **기술 스택**과 **MVP 개발 로드맵**을 단계별로 정리해 드립니다. [^1][^2][^3]

***

## 🛠️ 추천 기술 스택 (2026 기준)

### 1. 포즈 추정 및 컴퓨터 비전

| 레이어 | 기술 | 이유 |
| :-- | :-- | :-- |
| 포즈 추정 | **MediaPipe Pose** | 33개 키포인트, 실시간 처리, 모바일 최적화 |
| 영상 처리 | **OpenCV** | 프레임 추출, 슬로우모션, 오버레이 합성 |
| 영상 편집 | **FFmpeg / MoviePy** | 인코딩, 오디오 처리, 슬로우모션 효과 |
| 데이터 전처리 | **Pandas, NumPy, SciPy** | 키포인트 좌표 스무딩, 속도/가속도 계산 |

| 레이어 | 기술 | 이유 |

| 플랫폼 | 기술 | 이유 |

| 프로덕션 | **Next.js / React** | 확장성 있는 웹 앱 |

### 4. 백엔드 및 인프라

- **Notion / Jira**: 프로젝트 관리

## 🚀 MVP 개발 로드맵 (8주 기준)

### **1주차: 환경 설정 및 데이터 수집**

- **목표**: 개발 환경 구축, 스윙 영상 데이터셋 확보
- **할 일**:
    - GitHub 저장소 생성 (예: `golf-swing-analyzer`)
    - Google Colab Pro 세팅 (GPU 학습용)
    - 공개 데이터셋 다운로드 (CaddieSet, YouTube PGA 스윙)
    - MediaPipe + OpenCV 테스트 코드 작성
- **산출물**: 영상 로딩 → 포즈 추정 → 키포인트 추출 파이프라인 [^2][^4]


### **2-3주차: 포즈 추정 및 스윙 단계 분할**

- **목표**: 스윙 영상 → 관절 각도 계산 → 단계 자동 분할
- **할 일**:
    - MediaPipe 로 33개 키포인트 추출 (x, y, z, visibility)
    - 손목/어깨/골반 궤적 스무딩 (SciPy 필터)
    - 속도/가속도 기반으로 스윙 단계 분할 (Address → Backswing → Top → Downswing → Impact → Follow-through)
    - 관절 각도 계산 (예: 척추 기울기, 손목 코킹, 무릎 각도)
- **산출물**: 각도/속도/단계 데이터 (CSV/JSON) [^1][^2]


### **4주차: 프로 스윙 비교 엔진**

- **목표**: 사용자 스윙 vs PGA 프로 스윙 사이드바이사이드 비교
- **할 일**:
    - YouTube Shorts 에서 PGA 프로 스윙 다운로드 (yt-dlp)
    - 동일 프레임 수로 정규화 (예: 60fps → 30fps)
    - 키포인트 오버레이 합성 (OpenCV)
    - 슬로우모션 구간 자동 생성 (임팩트 전후 0.5초)
- **산출물**: 비교 영상 (MP4), 디버그 플롯 (Matplotlib) [^1]


### **5-6주차: 교정 피드백 엔진 (ML)**

- **목표**: 스윙 품질 점수 예측 + 텍스트/오디오 피드백 생성
- **할 일**:
    - 특징 공학: 각도, 속도, 템포, 대칭성 등 20+ 피처 추출
    - 분류 모델 학습: "Good/Average/Needs Improvement" (TensorFlow/PyTorch)
    - 피드백 규칙 엔진: "백스윙 시 왼팔이 굽었습니다 → 팔을 펴세요"
    - TTS (Text-to-Speech): 피드백 음성 생성 (Google TTS / Azure TTS)
- **산출물**: 품질 점수 (0-100), 교정 팁 (텍스트/음성) [^5][^6]


### **7주차: 앱 UI/UX 개발 (MVP)**

- **목표**: Streamlit/Gradio 로 웹 데모 → Flutter/React Native 로 앱 전환 준비
- **할 일**:
    - Streamlit 데모: 영상 업로드 → 분석 → 결과 표시
    - UI/UX 디자인: Figma 로 메인 화면 (촬영/업로드/결과/리포트)
    - 앱 프레임워크 선택: Flutter (Dart) 또는 React Native (TypeScript)
- **산출물**: 웹 데모 (Streamlit), UI 디자인 (Figma) [^5]


### **8주차: 테스트 및 배포**

- **목표**: MVP 배포, 초기 사용자 피드백 수집
- **할 일**:
    - Docker 컨테이너로 백엔드 패키징
    - AWS S3 + Lambda 로 서버리스 배포
    - 테스트 사용자 10명 모집 (골프 동호회, 지인)
    - 피드백 수집 (Notion 설문, Google Forms)
- **산출물**: MVP 앱 (웹/모바일), 피드백 리포트

## 📦 MVP 핵심 기능 (우선순위)

| 순위 | 기능 | 기술 |
| :-- | :-- | :-- |
| 1 | 스윙 영상 촬영/업로드 | Flutter Camera / File Picker |
| 2 | 포즈 추정 (MediaPipe) | Python + MediaPipe Pose |
| 3 | 스윙 단계 분할 | NumPy/SciPy 기반 속도 분석 |
| 4 | 프로 스윙 비교 | OpenCV 오버레이 + FFmpeg |
| 5 | 교정 팁 (텍스트) | 규칙 기반 + ML 분류기 |
| 6 | 결과 리포트 (PDF) | ReportLab / PDFKit |
