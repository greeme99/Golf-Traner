# GolfDB 데이터셋으로 스윙 이벤트 분류기 학습시키는 방법

GolfDB 데이터셋으로 **8개 스윙 이벤트 분류기**를 학습시키는 방법을 단계별로 정리해 드립니다. [^1][^2][^3][^4]

***

## 📚 GolfDB 8개 스윙 이벤트

| 이벤트 | 설명 |
| :-- | :-- |
| 1. **Address** | 공 앞에 서서 준비 자세 |
| 2. **Toe-up** | 백스윙 시작, 클럽 토가 위를 향함 |
| 3. **Mid-backswing** | 백스윙 중간 |
| 4. **Top** | 백스윙 정점 |
| 5. **Mid-downswing** | 다운스윙 중간 |
| 6. **Impact** | 공과 클럽 임팩트 |
| 7. **Mid-follow-through** | 팔로우스루 중간 |
| 8. **Finish** | 스윙 완료 자세 |

### **3단계: 모델 아키텍처 (SwingNet)**

GolfDB 의 공식 모델 **SwingNet**은 CNN + Bi-LSTM 결합 구조입니다. [^1][^3]

```python
# model.py (SwingNet)
import torch
import torch.nn as nn
from torchvision.models import mobilenet_v2, MobileNetV2_Weights

class EventDetector(nn.Module):
    def __init__(self, num_events=8, seq_length=19):
        super(EventDetector, self).__init__()
        
        # 1. 공간 특징 추출 (MobileNetV2)
        self.mobilenet = mobilenet_v2(weights=MobileNetV2_Weights.IMAGENET1K_V1)
        self.mobilenet.classifier = nn.Identity()  # 1280-dim 출력
        self.feature_dim = 1280
        
        # 2. 시간적 특징 학습 (Bi-LSTM)
        self.lstm = nn.LSTM(
            input_size=self.feature_dim,
            hidden_size=256,
            num_layers=2,
            batch_first=True,
            bidirectional=True,
            dropout=0.3
        )
        
        # 3. 이벤트 분류 (Fully Connected)
        self.fc = nn.Sequential(
            nn.Linear(256 * 2, 128),  # bidirectional
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, num_events)
        )
        
        self.seq_length = seq_length
    
    def forward(self, x):
        # x: (batch, seq_length, 3, 160, 160)
        batch_size = x.size(0)
        
        # MobileNetV2 로 공간 특징 추출
        features = []
        for t in range(self.seq_length):
            frame = x[:, t, :, :, :]  # (batch, 3, 160, 160)
            feat = self.mobilenet(frame)  # (batch, 1280)
            features.append(feat)
        
        features = torch.stack(features, dim=1)  # (batch, seq_length, 1280)
        
        # Bi-LSTM 로 시간적 특징 학습
        lstm_out, (h_n, c_n) = self.lstm(features)
        
        # 마지막 타임스텝 출력 사용
        final_hidden = torch.cat((h_n[-2], h_n[-1]), dim=1)  # (batch, 512)
        
        # 이벤트 분류
        logits = self.fc(final_hidden)  # (batch, 8)
        
        return logits
```


### **4단계: 학습 코드**

```python
# train.py
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, Dataset
from model import EventDetector
from dataloader import GolfDBDataset  # 데이터로더 구현 필요

# 하이퍼파라미터
config = {
    'batch_size': 32,
    'seq_length': 19,  # 19개 프레임 시퀀스
    'num_epochs': 50,
    'learning_rate': 1e-3,
    'num_events': 8
}

# 데이터 로더
train_dataset = GolfDBDataset(
    split_file='data/splits/split1_train.csv',
    video_dir='data/videos_160',
    seq_length=config['seq_length']
)
train_loader = DataLoader(train_dataset, batch_size=config['batch_size'], shuffle=True)

# 모델, 손실 함수, 옵티마이저
model = EventDetector(num_events=config['num_events'], seq_length=config['seq_length'])
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=config['learning_rate'])
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=20, gamma=0.1)

# 학습 루프
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

for epoch in range(config['num_epochs']):
    model.train()
    total_loss = 0
    
    for batch_idx, (frames, labels) in enumerate(train_loader):
        frames = frames.to(device)  # (batch, seq_length, 3, 160, 160)
        labels = labels.to(device)  # (batch,)
        
        # 순전파
        logits = model(frames)
        loss = criterion(logits, labels)
        
        # 역전파
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
    
    # 학습률 스케줄링
    scheduler.step()
    
    # 에포크별 로그
    avg_loss = total_loss / len(train_loader)
    print(f'Epoch {epoch+1}/{config["num_epochs"]}, Loss: {avg_loss:.4f}')
    
    # 모델 저장
    if (epoch + 1) % 10 == 0:
        torch.save(model.state_dict(), f'models/swingnet_epoch{epoch+1}.pth')
```


### **5단계: 평가 (PCE metric)**

GolfDB 는 **PCE(Percentage of Correctly Classified Events)** 를 주요 평가 지표로 사용합니다. [^1][^3]

```python
# eval.py
import torch
import numpy as np
from model import EventDetector
from dataloader import GolfDBDataset
from torch.utils.data import DataLoader

def calculate_pce(predictions, ground_truth, tolerance=1):
    """
    PCE 계산: 예측이 정답 프레임의 tolerance 이내면 정답
    """
    correct = 0
    total = len(ground_truth)
    
    for pred, true in zip(predictions, ground_truth):
        if abs(pred - true) <= tolerance:
            correct += 1
    
    return correct / total

# 테스트 데이터 로드
test_dataset = GolfDBDataset(
    split_file='data/splits/split1_test.csv',
    video_dir='data/videos_160',
    seq_length=19
)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

# 모델 로드
model = EventDetector(num_events=8, seq_length=19)
model.load_state_dict(torch.load('models/swingnet_epoch50.pth'))
model.eval()

# 예측
all_preds = []
all_labels = []

with torch.no_grad():
    for frames, labels in test_loader:
        frames = frames.to('cuda')
        logits = model(frames)
        preds = torch.argmax(logits, dim=1).cpu().numpy()
        
        all_preds.extend(preds)
        all_labels.extend(labels.numpy())

# PCE 계산
pce = calculate_pce(all_preds, all_labels, tolerance=1)
print(f'PCE: {pce:.3f}')  # 목표: 0.715+ (데이터 증강 시 0.761)
```

## 🎯 성능 개선 팁

### 1. **데이터 증강** (PCE +4.6% 향상)

- 수평 뒤집기 (좌우 스윙)
- 회전 (±5도)
- 밝기/대비 조정
- affine 변환

```python
# torchvision.transforms 사용
from torchvision import transforms

transform = transforms.Compose([
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomRotation(degrees=5),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], 
                         std=[0.229, 0.224, 0.225])
])
```


### 2. **모델 아키텍처 개선**

- **MobileNetV3** 또는 **EfficientNet**으로 변경 (더 가벼운 백본)
- **Transformer (ViT, TimeSformer)** 추가 (장기 의존성 학습)
- **Attention 메커니즘** (중요 프레임 가중치)


### 3. **하이퍼파라미터 튜닝**

- `seq_length`: 19 → 25 (더 긴 시퀀스)
- `batch_size`: 32 → 64 (GPU 메모리 여유 시)
- `learning_rate`: 1e-3 → 5e-4 (더 안정적 학습)
- `optimizer`: Adam → AdamW (가중치 감쇠)

## 📦 MVP 적용 예시

```python
# 실시간 스윙 이벤트 감지 (MVP 통합)
import cv2
import torch
from model import EventDetector
import mediapipe as mp

# 모델 로드
model = EventDetector(num_events=8, seq_length=19)
model.load_state_dict(torch.load('models/swingnet_epoch50.pth'))
model.eval()

# 이벤트 라벨 매핑
EVENTS = ['Address', 'Toe-up', 'Mid-backswing', 'Top', 
          'Mid-downswing', 'Impact', 'Mid-follow-through', 'Finish']

# 영상 분석
video = cv2.VideoCapture('user_swing.mp4')
frames_buffer = []

while video.isOpened():
    ret, frame = video.read()
    if not ret:
        break
    
    # 프레임 전처리 (160x160)
    frame_resized = cv2.resize(frame, (160, 160))
    frame_tensor = preprocess(frame_resized)  # (3, 160, 160)
    frames_buffer.append(frame_tensor)
    
    # 19개 프레임 버퍼 채워지면 예측
    if len(frames_buffer) == 19:
        input_seq = torch.stack(frames_buffer).unsqueeze(0)  # (1, 19, 3, 160, 160)
        
        with torch.no_grad():
            logits = model(input_seq)
            pred_event = torch.argmax(logits, dim=1).item()
        
        print(f'현재 이벤트: {EVENTS[pred_event]}')
        
        # 버퍼 시프트 (슬라이딩 윈도우)
        frames_buffer.pop(0)
```
