# MVP 단계에서 활용 가능한 무료 공개 골프 스윙 데이터셋이 있을까

MVP 단계에서 바로 활용 가능한 **무료 공개 골프 스윙 데이터셋**을 정리해 드립니다. [^1][^2][^3][^4][^5]

***

## 📊 추천 데이터셋 (MVP 우선순위)

### 1️⃣ **GolfDB** (가장 추천)

- **URL**: https://github.com/wmcnally/golfdb [^1]
- **크기**: 1,400개 고화질 스윙 영상 [^4]
- **포함 정보**:
    - 8개 스윙 이벤트 주석 (Address, Takeaway, Backswing, Top, Downswing, Impact, Follow-through, Finish)
    - 경계 상자 (Bounding Box)
    - 선수 이름, 성별, 클럽 종류, 뷰 타입 (Face-on, Down-the-line)
- **형식**: MP4 영상 + CSV 주석 파일
- **용도**: 스윙 단계 분할 모델 학습, 포즈 추정 검증
- **라이선스**: CC BY-NC 4.0 (비상업적 무료 사용 가능)
- **다운로드**: GitHub 에서 직접 또는 Hyper.ai 미러 (https://hyper.ai/en/datasets/21308) [^4]


### 2️⃣ **CaddieSet** (2025년 최신, CVPR 2025)

- **URL**: https://github.com/damilab/CaddieSet [^2][^6]
- **크기**: 924개 스윙 샷 (8명 골퍼, 다양한 클럽)
- **포함 정보**:
    - **관절 좌표**: 8개 스윙 단계별 Human Pose (HRNet 추출)
    - **공 정보**: 비거리, 방향각, 스핀축, 볼 속도
    - **15개 핵심 지표**: 도메인 전문가가 선정한 스윙 품질 피처
- **형식**: CSV (관절 좌표 + 공 데이터), MP4 영상
- **용도**: 스윙-공 궤적 상관관계 분석, 품질 예측 모델 학습
- **라이선스**: 학술/비상업적 무료 사용 (GitHub 확인 필요)
- **논문**: CVPR 2025 Workshops 게재 [^2][^7]


### 3️⃣ **Golf Swing Master** (Roboflow)

- **URL**: https://universe.roboflow.com/computer-vision-ewdmj/golf-swing-master [^3]
- **크기**: 2,571개 이미지 (골프 스윙 객체 감지)
- **포함 정보**: 바운딩 박스, 클래스 라벨
- **용도**: 골퍼 감지, 객체 인식 모델 학습
- **형식**: YOLO, COCO, Pascal VOC
- **라이선스**: 오픈소스 (Roboflow 표준)


### 4️⃣ **Golf Swing Performance Dataset** (Harvard Dataverse)

- **URL**: https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/SFYVDN [^5]
- **버전**: 1.2 (2026년 4월 업데이트)
- **포함 정보**: 스윙 성능 데이터 (정확한 스펙은 데이터셋 페이지 확인 필요)
- **용도**: 학술 연구, 성능 분석
- **라이선스**: 공개 데이터 (Harvard Dataverse 정책)


### 5️⃣ **Kaggle 골프 데이터셋**

- **URL**: https://www.kaggle.com/datasets?tags=2614-Golf [^8]
- **예시**:
    - "Golf Swing and Trajectory Data" (CSV, 80KB)
    - "PGA Tour Results | 2001 to December 2025"
- **용도**: 보조 데이터 (통계 분석, 스윙-결과 상관관계)

## 🎯 MVP 활용 전략

### **1단계: GolfDB 로 기본 파이프라인 구축**

- **목적**: 스윙 단계 분할, 포즈 추정 검증
- **방법**:

1. GolfDB 에서 Face-on 뷰 100개 샘플 다운로드
2. MediaPipe Pose 로 33개 키포인트 추출
3. 주석 파일 (8개 이벤트) 과 비교하여 정확도 측정
- **코드 예시**:

```python
# GolfDB 로드 및 MediaPipe 포즈 추정
import mediapipe as mp
import cv2

pose = mp.solutions.pose.Pose()
video = cv2.VideoCapture('golfdb_sample.mp4')

while video.isOpened():
    ret, frame = video.read()
    results = pose.process(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))
    # 키포인트 추출: results.pose_landmarks
```


### **2단계: CaddieSet 으로 품질 예측 모델 학습**

- **목적**: 스윙 품질 점수 (0-100) 예측
- **방법**:

1. CaddieSet 의 관절 좌표 CSV 로드 (15개 피처)
2. 공 정보 (비거리, 방향각) 를 타겟으로 회귀 모델 학습
3. TensorFlow/PyTorch 로 MLP 또는 LSTM 모델 구축
- **피처 예시**:
    - 백스윙 시 어깨 회전각
    - 임팩트 시 손목 코킹 각도
    - 팔로우스루 골반 회전 속도


### **3단계: Roboflow 로 골퍼 감지 모델 추가**

- **목적**: 다중 인물 영상에서 골퍼만 추출
- **방법**:

1. Roboflow 에서 "Golf Swing Master" 데이터셋 다운로드
2. YOLOv8-Pose 로 파인튜닝
3. 실시간 영상에서 골퍼 바운딩 박스 추출
