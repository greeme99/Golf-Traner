# SwingNet의 추론 성능을 향상시키기 위한 모델 튜닝 전략

SwingNet 의 추론 성능을 향상시키기 위한 **모델 튜닝 전략**을 정확도, 속도, 메모리 효율 측면에서 정리해 드립니다. [^1][^2][^3][^4][^6]

***

## 🎯 최적화 목표 설정

먼저 최적화 방향성을 명확히 합니다:


| 목표 | 전략 우선순위 |
| :-- | :-- |
| **정확도 향상** (PCE ↑) | 파인튜닝, 데이터 증강, 하이퍼파라미터 튜닝 |
| **추론 속도 향상** (지연 시간 ↓) | 양자화, 프루닝, 모델 경량화 |
| **메모리 효율** (모델 크기 ↓) | 양자화, 지식 증류, 프루닝 |
| **모바일 배포** | 양자화 (INT8), EfficientNet 백본, TFLite 변환 |


***

## 1️⃣ 정확도 향상 전략 (PCE ↑)

### **A. 하이퍼파라미터 튜닝**

```python
# 학습률 스케줄링 개선 (Cosine Annealing)
from torch.optim.lr_scheduler import CosineAnnealingLR

optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
scheduler = CosineAnnealingLR(optimizer, T_max=50, eta_min=1e-5)

# 배치 크기 증가 (GPU 메모리 여유 시)
# 32 → 64 → 128 (Gradient Accumulation 활용)
```

**권장 튜닝 범위**:

- `learning_rate`: 1e-3, 5e-4, 1e-4 (그리드 서치)
- `batch_size`: 32, 64, 128
- `weight_decay`: 1e-4, 1e-5
- `seq_length`: 19 → 25, 31 (더 긴 시퀀스)
- `optimizer`: Adam → AdamW (가중치 감쇠 추가)

### **C. 백본 모델 교체 (MobileNetV2 → EfficientNet)**

```python
from torchvision.models import efficientnet_b0, EfficientNet_B0_Weights

class SwingNet_EfficientNet(nn.Module):
    def __init__(self, num_events=8, seq_length=19):
        super().__init__()
        
        # EfficientNet-B0 백본 (더 정확하지만 약간 무거움)

        self.backbone.classifier = nn.Identity()  # 1280-dim 출력

            bidirectional=True,

        )
        
        # 분류기 (동일)
        self.fc = nn.Sequential(
            nn.Linear(256 * 2, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, num_events)
        )
        
        self.seq_length = seq_length
    
    def forward(self, x):
        # ... (기존과 동일)
```

**예상 효과**: MobileNetV2 대비 +2-3% PCE 향상, 추론 속도 10-15% 저하

### **D. Attention 메커니즘 추가**

```python
# Temporal Attention 레이어 추가
class TemporalAttention(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.attention = nn.Linear(hidden_dim, 1)
    
    def forward(self, lstm_out):
        # lstm_out: (batch, seq_length, hidden_dim)
        scores = self.attention(lstm_out)  # (batch, seq_length, 1)
        weights = torch.softmax(scores, dim=1)
        
        # 가중 평균
        weighted_sum = torch.sum(lstm_out * weights, dim=1)  # (batch, hidden_dim)
        return weighted_sum

# SwingNet 수정
self.attention = TemporalAttention(hidden_dim=256 * 2)

# forward() 에서 LSTM 출력 대신 attention 출력 사용
lstm_out, _ = self.lstm(features)  # (batch, seq_length, 512)
attended_features = self.attention(lstm_out)  # (batch, 512)
logits = self.fc(attended_features)
```

**효과**: 중요 프레임 (임팩트, Top) 에 집중하여 PCE +1-2% 향상

## 2️⃣ 추론 속도 최적화 (지연 시간 ↓)

### **A. 양자화 (Quantization)** [^1][^2][^4][^6]

**사후 학습 양자화 (PTQ)**: 가장 간단하고 빠른 최적화

```python
# PyTorch 동적 양자화 (추천)
import torch.quantization as quantization

# 1. 모델 준비 (quant/dequant 연산자 삽입)
model_quantized = quantization.quantize_dynamic(
    model,  # 원본 모델
    [],  # 연산자 목록 (비어 있으면 자동 감지)
    dtype=torch.qint8  # 8비트 정수 양자화
)

# 2. 저장
torch.save(model_quantized.state_dict(), 'swingnet_int8.pt')

# 3. 추론 (동일 API)
logits = model_quantized(frames)
```

**효과**:

- 모델 크기: FP32 (120MB) → INT8 (30MB, 75% 감소)
- 추론 속도: 1.5-2배 향상 (CPU)
- 정확도 손실: <1% (PCE 0.005 미만)

**양자화 인지 학습 (QAT)**: 더 높은 정확도 유지

```python
# QAT: 학습 과정에 양자화 시뮬레이션 포함
model.qconfig = quantization.get_default_qat_qconfig('fbgemm')
model_prepared = quantization.prepare_qat(model)

# 재학습 (1-2 에포크만)
for epoch in range(2):
    train(model_prepared, ...)  # 양자화 노이즈 포함 학습

# 실제 양자화 적용
model_quantized = quantization.convert(model_prepared)
```


### **B. 프루닝 (Pruning)** [^1][^5][^6]

가중치 중 0 에 가까운 값 제거 (희소성)

```python
import torch.nn.utils.prune as prune

# 1. LSTM 레이어 프루닝
prune.ln_unstructured(
    model.lstm,  # 대상 레이어
    name='weight_ih_l0',  # 가중치 이름
    l1=0.5  # 50% 제거
)

# 2. FC 레이어 프루닝
prune.ln_unstructured(
    model.fc[^0],
    name='weight',
    l1=0.3  # 30% 제거
)

# 3. 프루닝된 가중치 영구화
for name, module in model.named_modules():
    if isinstance(module, (nn.LSTM, nn.Linear)):
        prune.remove(module, 'weight')
```

**효과**: 모델 크기 30-50% 감소, 추론 속도 1.2-1.5배 향상

### **C. 백본 경량화 (MobileNetV3)**

```python
from torchvision.models import mobilenet_v3_small, MobileNet_V3_Small_Weights

class SwingNet_MobileNetV3(nn.Module):
    def __init__(self, num_events=8, seq_length=19):
        super().__init__()
        
        # MobileNetV3-Small (V2 대비 20% 가벼움)
        self.backbone = mobilenet_v3_small(weights=MobileNet_V3_Small_Weights.IMAGENET1K_V1)
        self.backbone.classifier = nn.Identity()  # 576-dim 출력
        self.feature_dim = 576
        
        # LSTM (입력 차원 조정)
        self.lstm = nn.LSTM(
            input_size=self.feature_dim,
            hidden_size=128,  # 256 → 128 (경량화)
            num_layers=2,
            batch_first=True,
            bidirectional=True,
            dropout=0.3
        )
        
        self.fc = nn.Sequential(
            nn.Linear(128 * 2, 64),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, num_events)
        )
        
        self.seq_length = seq_length
```

**효과**:

- 모델 크기: 120MB → 40MB
- 추론 속도: 2-3배 향상 (모바일)
- 정확도 손실: 1-2% (PCE 0.70-0.71)

## 3️⃣ 메모리 효율 최적화

### **A. 지식 증류 (Knowledge Distillation)** [^1][^5][^6]

"교사 모델" (SwingNet) → "학생 모델" (경량화)

```python
class DistillationLoss(nn.Module):
    def __init__(self, temperature=4, alpha=0.7):
        super().__init__()
        self.temperature = temperature
        self.alpha = alpha
        self.ce = nn.CrossEntropyLoss()
    
    def forward(self, student_logits, teacher_logits, labels):
        # soft loss (교사 모델 예측과 일치)
        soft_loss = nn.KLDivLoss()(
            F.log_softmax(student_logits / self.temperature, dim=1),
            F.softmax(teacher_logits / self.temperature, dim=1)
        ) * (self.temperature ** 2)
        
        # hard loss (정답 라벨과 일치)
        hard_loss = self.ce(student_logits, labels)
        
        return self.alpha * soft_loss + (1 - self.alpha) * hard_loss

# 학습 루프
for batch_idx, (frames, labels) in enumerate(train_loader):
    # 교사 모델 순전파 (학습 없음)
    with torch.no_grad():
        teacher_logits = teacher_model(frames)
    
    # 학생 모델 순전파
    student_logits = student_model(frames)
    
    # 증류 손실 계산
    loss = distillation_loss(student_logits, teacher_logits, labels)
    
    # 역전파
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

**효과**: 학생 모델이 교사 모델의 95-98% 성능 달성, 크기 50-70% 감소

### **B. 그레이디언트 체크포인팅 (Gradient Checkpointing)**

```python
# 메모리 사용량 감소 (배치 크기 증가 가능)
from torch.utils.checkpoint import checkpoint

class SwingNet_MemoryEfficient(nn.Module):
    def forward(self, x):
        # MobileNetV2 백본 (메모리 집약적)
        def custom_forward(frames):
            features = []
            for t in range(self.seq_length):
                frame = x[:, t, :, :, :]
                feat = self.mobilenet(frame)
                features.append(feat)
            return torch.stack(features, dim=1)
        
        features = checkpoint(custom_forward, x)  # 메모리 절약
        
        # LSTM
        lstm_out, _ = self.lstm(features)
        final_hidden = torch.cat((lstm_out[-2], lstm_out[-1]), dim=1)
        
        logits = self.fc(final_hidden)
        return logits
```

**효과**: GPU 메모리 40-50% 감소 → 배치 크기 2 배 증가 가능
